# Установка Gold Parser (для клиента)

Gold Parser — бот, который ищет выгодные радиодетали с драгметаллами
(золото/палладий/платина) на Авито и Мешке и присылает сигналы в Telegram.
Металл в детали должен быть ≥ 3× цены лота — на этом считаете профит.

## Быстрый старт (Windows)

### 1. Установи Python
- Скачай [Python 3.11+](https://www.python.org/downloads/) (однократно).
- При установке отметь **«Add Python to PATH»**.

### 2. Поставь зависимости
Открой папку проекта в `cmd` (адресная строка → введи `cmd` → Enter) и выполни:

```
pip install -r requirements.txt
```

### 3. Проверь, что всё работает

```
python tests.py
```

Должно вывести `Итог: 88 ok, 0 fail`.

### 4. Базовая проверка цен и поиска

```
python app.py prices            # цены золота/палладия/платины
python app.py scan "микросхемы К155" --pages 3   # поиск по Авито+Мешку
```

При первом скане откроется окно браузера — **кликни капчу «я не робот» один раз**
(профиль запомнит, дальше автоматически). Внизу вывода появятся «ВЫГОДНЫЕ —
чистые ссылки».

### 5. Запусти Telegram-бота (для подписчиков)

1. Создай бота у [@BotFather](https://t.me/BotFather): команда `/newbot`,
   получи токен.
2. Вставь токен в файл `data/tg_token.txt` (создай папку data, если её нет).
3. Запусти бота:

```
python -m bot.telegram_bot
```

Подписчики пишут боту: `/start`, `/subscribe`, `/scan <запрос>`, `/good`,
`/stats`, `/settings`.

### 6. Автопостинг в канал (для PRO-подписок)

Монитор сам постит выгодные лоты в закрытые каналы:

```
python app.py monitor --post-to -1001234567890 --post-to-pro -1001234567891
```

Для этого ты должен добавить бота **админом** в оба канала и подставить их ID
(см. `bot/poster.py` и `.env.example`).

## Вариант для сервера (Linux/VPS, экспериментально)

Проект оптимизирован под **Windows** (использует локальный Chrome и путь
`C:\Users\...`). Перенос на Linux/VPS требует правки путей (`BASE`) и установки
Chrome+драйвера под Linux. Заготовка: `Dockerfile` и `docker-compose.yml`.
Полная продакшен-настройка на Linux — отдельная задача, обратись к автору.

## Структура (коротко)

- `app.py` — команды CLI: `prices`, `scan`, `hunt`, `monitor`, `stats`, `export`, `uc`, `boards`, `shops`.
- `board_uc.py` — парсинг Авито/Мешка/Юлы через браузер (обход капчи).
- `components.csv` — справочник 164 деталей с содержанием Au/Pd/Pt.
- `bot/` — Telegram-бот: `telegram_bot.py`, `db.py` (база подписчиков), `payments.py` (оплата), `poster.py` (постинг в канал).
- `data/` — базы, токены, профили браузера, кэш цен, история.
- `output/` — отчёты CSV/XLSX.

## Требования

- Python 3.11+
- Google Chrome (та версия, что стоит на машине; если меняешь — обнови
  `CHROME_MAIN` в `board_uc.py`)
- Интернет + доступ к Авито/Мешку (обычный, без VPN — площадки блокируют Tor/VPN-IP)

## Команды «для работы»

```
python app.py scan "микросхемы К155" --pages 5    # найти выгодные лоты
python app.py hunt --pages 5                       # всё выгодное по 28 ключам
python app.py monitor --post-to-pro -100...        # фоновая слежка + постинг
python app.py stats                                # статистика работы
python app.py export --format xlsx                 # история в Excel
```
