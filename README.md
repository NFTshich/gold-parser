# Gold Parser — оценка радиодеталей с драгметаллами

Бот для поиска и оценки лотов (микросхемы, транзисторы, конденсаторы КМ, реле,
разъёмы, платы, радиостанции, лампы и т.п.), в которых содержатся драгметаллы.
Идея: купить лот так, чтобы стоимость металла была в 3 и более раз выше цены лота.

### Драгметаллы
Золото (Au), палладий (Pd), платина (Pt). Серебро (Ag) по ТЗ учитывается в ценах,
но **в маржу НЕ входит** (см. `config.INTERESTED_METALS`).

---

## Установка

Нужен **Python 3.10+** (проверено на 3.12). Внешние библиотеки не требуются —
используются только стандартные модули (`requests` есть в системе по умолчанию,
если нет — `pip install requests`). `beautifulsoup4` нужен лишь при написании
своих парсеров площадок (опционально).

## Запуск

**Проще всего:** двойной клик по `run.bat` — откроется простое меню:
```
  1. Цены драгметаллов (ЦБ РФ за грамм)
  2. Прайсы скупщиков (что платят за детали)
  3. Сканировать VK-группы и Telegram-каналы
  4. Оценить один лот (описание + цена)
  5. Ввести лоты вручную (накопировать с сайта)
  6. Импорт лотов из CSV-файла
  7. Самопроверка (тесты)
  8. Куда смотреть отчёты и настройки
  9. Найти выгодные лоты в VK и открыть их в браузере для покупки
 10. Форум-барахолка radiokot (объявления о продаже)
 11. Монитор: ловить новые выгодные объявления (Ctrl+C — выход)
  0. Выход
```
В любом отчёте у каждого лота показывается **ссылка на источник**. Пункт **9**
сам сканирует VK + барахолку, оставляет лоты с маржой «металл ≥ 3× и ≥ 100 ₽»
со ссылкой и открывает их в твоём браузере для покупки.

### Мониторинг — ловить новые выгодные лоты
`python app.py monitor` (или пункт 11 меню) постоянно сканирует лёгкие источники
(Telegram + radiokot) и показывает только **новые** объявления, где металл
≥ 3× цены, со ссылкой. Повторы не дублируются (память в `data/seen.json`).
Флаги:
- `--every N` — интервал в секундах (по умолчанию 240);
- `--x N` — порог кратности (например `--x 5` — только металл ≥ 5× цены);
- `--auto-open` — автоматически открывать найденные лоты в браузере;
- `--vk` — добавить VK (тяжелее, через Chrome);
- `--slow` — добавить медленные барахолки (zx-pk, vkupiprodai).
При каждой находке — звуковой сигнал. Остановить — Ctrl+C.

### Металлы
Учитываются только **золото (Au), платина (Pt), палладий (Pd)**. Серебро и
цветмет (алюминий/медь) полностью исключены из цен и расчёта маржи.

### Про Авито, Мешок, Юлу
Прямой парсинг Авито/Мешка/Юлы **заблокирован** (проверено): они грузят
объявления JS-запросами, требуют входа и отсекают автоматику (Авито 429/капча
даже в headless-браузере, Мешок отдаёт пустую оболочку, Юла — только JS).
Это намеренное противодействие парсингу.

**Рабочий «обход» площадок — агрегаторы в Telegram.** Каналы, которые
перепощещивают объявления с Авито/Мешка с ценой и ссылкой на оригинал,
читаются через `t.me/s/<канал>` (наш парсер забирает из поста цену и ссылку на
сам лот площадки). Пример уже подключён: **@svezzakk** («Свежак | Новые
объявления Avito», в постах кнопка «Открыть на Avito»). Мы читаем агрегатор,
а открывается и покупается на самом Авито.

### Источники продавцов (мы покупаем)
`social_channels.py` разделён на `SELLER_CHANNELS` (продавцы — сканируются)
и `BUYER_CHANNELS` (скупщики — выключены из круга покупки, спамят маркетингом).
Продавцы:
- **radiokot** (форум-барахолка, команда `boards`);
- **@board_radio** — QRX, доска объявлений радиолюбителей (6.2 тыс.);
- **@svezzakk** — свежие объявления Авито (цена + ссылка на Авито);
- **@ITbarakholka**, **@barakholka_ufa1**, **@avitonovokuznezk**, **@donetskbu**,
  **@kuplyprodammoskwa** — общие барахолки, где бывают радиодетали/техника.
В пункте 3 бот спросит, доступен ли Telegram (если `t.me` только через VPN —
отвечай «нет», и он сканирует только VK), и нужно ли подгрузить больше постов.

**Или командами напрямую** (для автоматизации/скриптов):

```bash
python app.py prices                                  # цены ЦБ за грамм
python app.py calc "КМ-5 конденсаторы палладий 100шт" -p 4000
python app.py eval                                    # вставить лоты построчно
python app.py import лоты.csv                         # импорт из CSV
python app.py social                                  # Telegram + VK (без токена)
python app.py social --no-tg                          # только VK (без t.me)
python app.py social --no-tg --limit 60               # больше постов со стен
python app.py shops                                   # прайсы скупщиков (работает сразу)
python app.py shops --category реле                   # один раздел
python app.py vksearch "микросхемы с золотом"         # по всему VK (опционально токен)
python app.py vksearch "реле КМ" --market             # в товарах VK (опционально токен)
python app.py boards                                  # форум-барахолка radiokot
python app.py boards --forum 52                       # один раздел
python app.py search "микросхемы с золотом"           # площадки (см. ниже)
python tests.py                                       # самопроверка без интернета
```

На Windows удобно: `run.bat`.

## Как пользоваться

1. **Узнай цены металлов** `python app.py prices` — курс берётся из Банка России
   автоматически (учётные цены за грамм, публикуются по рабочим дням).
2. **Найди лоты** на Авито/Мешке/Юле (у них жёсткий антибот — скрапить напрямую
   почти нереально, поэтому вручную, быстро).
3. **Введи их в бота** двумя способами:
   - `python app.py eval` — вставляешь построчно: `Заголовок — цена руб`
   - или сохрани в CSV (`title;price;url`) и `python app.py import файл.csv`
4. Бот подбирает тип детали из справочника, умножает содержание металла на
   количество «шт» (если указано) и считает **стоимость металла, маржу и кратность**.
   Лот с пометкой **ВЫГОДНО** = «металл ≥ 3× цены и маржа ≥ 500 руб».
5. Отчёт пишется в `output/report_*.csv` (кириллица в Excel читается корректно).

Пример (`sample_lots.csv`): `python app.py import sample_lots.csv`

## Логика «металл в 3× цены»

```
metal_value = Au_г·Цаu + Pd_г·Цpd + Pt_г·Цpt
ratio = metal_value / цена_лота
net   = metal_value − цена_лота
ВЫГОДНО  ⇔  ratio ≥ 3  И  net ≥ 500 руб
```

Пороги `3.0` и `500` меняются в `config.py` (`MIN_RATIO`, `MIN_NET_PROFIT_RUB`).

## Справочник деталей (`components.csv`)

- Запись = **один тип детали** и ориентировочное содержание металлов **на одну
  единицу** (миллиграммы), диапазоны `аu_mg..аu_hi`, `pd_mg..pd_hi`, `pt_mg..pt_hi`.
- Реальные партии сильно различаются — **значения в файле это ориентир,
  уточняй по факту** и правь файл. Учитывай также, что при аффинаже/перепродаже
  есть технологические потери и расходы — закладывай их в порог `MIN_RATIO`.
- Распознавание по «ключевым словам» из названия (коды модели) и описания.
- Для лота берётся **лучшее одиночное совпадение** (самый специфичный тип) —
  оценка консервативная, не завышенная. Смешанные лоты разбивай на строки.
- Если знаешь точное содержание (например «плата с 0.5 г золота») — заведи
  более точную строку в CSV под конкретную позицию.

## Соцсети: Telegram и VK (`social`)

Каналы и группы в соцсетях — главное место, куда уехала продажа/скупка
радиодеталей. Команда `python app.py social` сканирует сразу два источника:

**Telegram** — читает **публичные web-превью каналов** `t.me/s/<username>`
(без логина и токена, только чтение). Берёт последние сообщения, распознаёт
цену и тип детали и оценивает их как в `eval`. Бот ничего не постит/не шлёт.
Нужен обычный доступ к `t.me` (просто HTTPS).

**VK — работает БЕЗ токена.** Официальный API VK требует access_token, а посты
на сайте грузятся JS. Поэтому бот запускает твой локальный **Chrome/Edge**
в headless-режиме, страница сама исполняет JS и отдаёт DOM, который бот парсит
(см. `vkbrowser.py`). Никакой авторизации — читаются только открытые стены
публичных групп. Нужен лишь установленный Chrome или Edge на машине.

**VK с токеном (опционально)** расширяет возможности: `vksearch "запрос"` ищет
по **всему VK** через `newsfeed.search`/`market.search`. Токен — только если
нужно это: создать приложение на vk.com/dev и положить токен в `VK_TOKEN`
или `data/vk_token.txt`.

Списки каналов/групп лежат в **`social_channels.py`** и предзаполнены
реально существующими источниками (найдены поиском):
- **Telegram**: `RAdIODETALI180`, `astreyaradiodetali`, `kuplyprodammoskwa` +
  тематические каналы скупки радиодеталей: `skupkaRaduga`, `skupka_radiodetali`,
  `pokupkaradiolom`, `rgoldpro`, `skupkaradiodetalidonetsk` и барахолки
  `ITbarakholka`, `avitonovokuznezk`;
- **VK**: `rdmsb`, `skupka_radiodetalei`, `club109505426`, `radiodetali_dnr_lnr`,
  `tochkasboraru`.
Дописывай свои — имя произвольное, значение это `username` (без `@`).

**Ссылка на источник:** у каждого найденного лота в отчёте (CSV) и в консоли
указывается ссылка — на пост или на само объявление. Если в посте Telegram есть
внешняя ссылка на площадку (Авито/Мешок/Юла и т.п.), бот ведёт на неё —
удобно для перехода к покупке.

Запуск:
```bash
python app.py social                      # Telegram + VK
python app.py social --channel <tg-канал> # только указанный Telegram-канал
```

## Прайсы скупщиков (`shops`)

Показывает текущие закупочные цены реальных перекупщиков радиодеталей
(что они готовы платить за деталь с драгметаллами — это реалистичная цена
«выхода» при перепродаже и калибровка для справочника). Работает сразу,
без токена: данные берутся из серверного HTML каталога скупщика
(по умолчанию astreya-radiodetali.ru, ~500 позиций по 7 категориям).
Источники и разделы настраиваются в `config.SHOP_SOURCES`.

## Поиск по площадкам (`search`)

Авито/Мешок/Юла и многие барахолки режут простой `requests`-скрапинг (антибот,
JS, редиректы) — это подтверждено. Поэтому надёжный путь — ручной/пакетный ввод.
Каркас для парсеров оставлен в `scraper.py` (`ScraperAdapter`, `SITE_ADAPTERS`):
можно дописать адаптер под любимую площадку (лучше на Selenium) и подключить его.

## Цены: надёжность

Источники по приоритету (`prices.py`):
1. ручная цена → `data/manual_prices.json` (шаблон `manual_prices.example.json`);
2. официальный ЦБ РФ `cbr.ru/scripts/xml_metall.asp` (учётные цены за грамм);
3. зеркало cbr-xml-daily (страховка от «стены согласия» ЦБ);
4. кэш `data/metal_prices.json` (последние успешные цены).

Если в сети всё закрыто, кэш может содержать демо-значения — при первом живом
запуске реальные цены ЦБ его перезапишут.

## Структура

```

scraper.py        ручной/пакетный ввод + каркас парсеров площадок
social.py         Telegram (t.me/s) + VK (API/токен): группы и поиск по VK
vkbrowser.py      VK без токена: рендер публичной стены локальным Chrome/Edge
social_channels.py  список каналов/групп для сканирования
shops.py          прайс-листы скупщиков радиодеталей
boards.py         форум-барахолка radiokot (авитоподобный источник)
shops            config.SHOP_SOURCES — разделы каталогов скупщиков
config.py         пороги 3×/500р, пути, запросы

output/           отчёты CSV
data/             кэш цен
tests.py          самопроверка без интернета
```

## Важно

Скупка и переработка радиодеталей с драгметаллами — легальная деятельность.
**Аффинаж (извлечение металлов в чистый вид) в РФ — лицензируемый вид
деятельности** (ФЗ-41 «О драгоценных металлах»). Если планируешь именно аффинаж,
изучи требования к лицензии. Оценка содержания по справочнику — ориентировочная.
